# Alineamiento ISO

Radio Rumbo no esta certificado bajo normas ISO en esta Fase 0. La documentacion adopta estas normas como referencia de buenas practicas para orientar seguridad, calidad, ciclo de vida y pruebas.

## Referencias

- ISO/IEC 27001: referencia para gestion de seguridad de la informacion, control de accesos, tratamiento de riesgos y proteccion de credenciales.
- ISO/IEC 25010: referencia para calidad del producto software, incluyendo mantenibilidad, seguridad, confiabilidad, compatibilidad y usabilidad.
- ISO/IEC/IEEE 12207: referencia para procesos del ciclo de vida del software, desde requisitos hasta mantenimiento.
- ISO/IEC 29110: referencia para proyectos pequenos y equipos reducidos con procesos livianos.
- ISO/IEC/IEEE 29119: referencia para estrategia, documentacion y ejecucion de pruebas de software.

## Aplicacion en el proyecto

El proyecto usa estas normas como guia, no como declaracion formal de cumplimiento. Cualquier certificacion futura requeriria auditoria, evidencias, politicas organizacionales y procesos operativos adicionales.
